## Production Workflow

The project used a staged pipeline that kept capture, model processing, animation transfer, and final composition separate:

**Vicon and Shogun → Blender model processing → MotionBuilder animation transfer → Unreal Engine composition**

## Project Context

The Buried Lumen was created for *VIZA 619 Motion Capture Animation*. The project focused on combining motion-capture performance with a real-time cinematic production workflow.
